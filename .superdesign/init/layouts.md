# Layouts

No shared layouts exist yet. `lib/main.dart` currently uses a single `Scaffold` generated by the Flutter template; there is no navigation bar, sidebar, header, footer, or responsive shell.

## Current root shell — `lib/main.dart`

`MaterialApp` provides the app root and `MyHomePage` renders a default `Scaffold` with an `AppBar`, centered body, and floating action button. The future storefront should replace this with a reusable responsive shell supporting Arabic RTL and English LTR.
